# 株式会社ENTER Roadmap

## 目的
株式会社ENTERの経営・業務・AI活用・仕組み化を一元管理し、会社の成長に合わせて継続的に改善していくためのロードマップ。

## 基本方針
- 経営の仕組み化
- 業務の標準化・自動化
- AIを活用した業務効率化
- データを活用した経営判断
- 属人化の削減
- KPIの可視化
- 将来の事業拡大に対応できる会社基盤の構築

## 今後つくる仕組み
- 経営ダッシュボード
- 売上・利益・経費の管理
- ドライバー管理
- 案件管理
- 採用・人材管理
- 営業管理
- 請求・入金管理
- 業務マニュアル
- AIエージェント・自動化
- Googleスプレッドシート等とのデータ連携
- MindMeisterによる会社全体ロードマップ管理
- GitHub / Codexによるシステム開発・改善管理

## 開発ルール
このリポジトリを株式会社ENTERのロードマップと仕組み化の基盤として使用する。

新しいアイデア、課題、改善案、システム開発については、このロードマップとの整合性を確認しながら追加・更新していく。

最終的には、会社の数字・業務・意思決定をできる限り一元化し、AIとデータを活用して会社全体が効率的に動く仕組みを構築する。
